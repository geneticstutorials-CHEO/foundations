Comment le construire

1
Coupez le chromosome. Visez un + dans la bande à côté d'un chromosome : une étiquette indique ce qui se détache, par exemple « q11.2 et en dessous ». Cliquez pour couper. Sur un téléphone, touchez l'endroit, lisez l'étiquette, puis appuyez sur Couper. Le x rouge enlève une coupure.
2
Déplacez un segment. Glissez-le sur un chromosome pour l'y rattacher, laissez-le sur le tapis, ou déposez-le sur Rejeter pour le supprimer.
⟲
Retournez un segment. Touchez le bouton de rotation pour le retourner.
⧉
Dupliquez un segment. Touchez le bouton de copie pour ajouter une deuxième copie.
✓
Vérifiez, classez, expliquez. Appuyez sur Vérifier, classez le changement, puis dites-le en mots simples au patient.
Chaque rayure est une bande. Les couleurs indiquent de quel chromosome provient un segment. Une bande déplacée sur un autre chromosome, ou posée sur le tapis, garde son chromosome d'origine dans son étiquette (par exemple 22q12). X et Y se trouvent dans le coin. Un symbole de maillon dans la bande indique un endroit où deux segments sont réunis; un x rouge indique une coupure. Les gènes importants sont mis en évidence à côté de la bande qu'ils occupent sur le chromosome.
