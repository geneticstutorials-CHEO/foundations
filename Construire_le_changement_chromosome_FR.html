Comment le construire

1
Ajoutez un point de cassure. Cliquez sur un + dans la bande à côté d'un chromosome. Il s'aligne sur l'interbande la plus proche. Cliquez sur le x pour l'enlever.
2
Déplacez un segment. Glissez-le sur un chromosome pour l'y rattacher, laissez-le sur le tapis, ou déposez-le sur Rejeter pour le supprimer.
⟲
Retournez un segment. Touchez le bouton de rotation pour le retourner.
⧉
Dupliquez un segment. Touchez le bouton de copie pour ajouter une deuxième copie.
✓
Vérifiez, classez, expliquez. Appuyez sur Vérifier, classez le changement, puis dites-le en mots simples au patient.
Chaque rayure est une bande. Les couleurs indiquent de quel chromosome provient un segment. Une bande déplacée sur un autre chromosome, ou posée sur le tapis, garde son chromosome d'origine dans son étiquette (par exemple 22q12). X et Y se trouvent dans le coin. Les gènes importants sont mis en évidence à côté de la bande qu'ils occupent sur le chromosome.
